# Team & Pinned-Game Push Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Push tip-off, close-finish/overtime and final-score alerts for the user's favourite team and pinned games/players, with per-type on/off toggles.

**Architecture:**
- **Data:** two new tables, `push_preferences` and `watch_pins`.
- **Logic:** a pure-plus-DB service `services/teamPush.ts` (alert conditions, recipients, copy), called fire-and-forget from `sync/liveGamesSync.ts`.
- **API and UI:** routes for preferences and pins; the frontend syncs pins and shows six toggles on Profile.

**Tech Stack:** Express 4 + Drizzle (postgres-js) + web-push (`services/push.ts`); Angular 20.

**Spec:** `docs/superpowers/specs/2026-10-12-team-push-design.md`

## Global Constraints

- **Tables:** exactly the spec's SQL. Applied by hand to dev **and** production.
- **Defaults:** a missing preferences row means every type is on.
- **Sending:** every push goes through `sendPushOnce(kind, key, userIds, build)`.

  | Alert | `kind` | `key` |
  |---|---|---|
  | Tip-off | `team_tipoff` | `tipoff:<gameId>` |
  | Close finish / OT | `team_close` | `close:<gameId>` |
  | Final score | `team_final` | `final:<gameId>` |

- **When each fires:**
  - tip-off: `tipoff_at` is 10–20 min ahead and the game is `scheduled`
  - close: live, `quarter >= 4`, `game_clock_seconds <= 120`, margin ≤ 3; **or** `quarter >= 5`
  - final: on the transition to `final`
- **Recipients:** fans (`favorite_team_id` in home/away), plus pinners (`watch_pins.game_id` = this game) for close and final. Exclude `deleted_at` users and anyone whose preference for that kind is false. Pinners are filtered by `pinned`.
- **Copy (EN, verbatim; EL written alongside):**
  - "{HOME} vs {AWAY} starts in 15 minutes. Make your picks."
  - "Close finish: {HOME} {hs}–{as} {AWAY}, {clock} left."
  - "{HOME}–{AWAY} is going to overtime."
  - "Final: {HOME} {hs}–{as} {AWAY}." For pinned players, append " {Player}: {pts} pts."
- **URL:** `/games/<id>`.
- **Existing jobs:** picks and fantasy reminders honour `lock_reminders`; round results honour `round_results`.
- **Pin limit:** 3, enforced on the server too.
- **Safety:** nothing in the push path may throw into the live sync.

## Review Focus

1. **A fan who also pinned the game** gets one final push, not two. `sendPushOnce` dedupes per (user, kind, key). Task 2 test: `recipientsFor` returns unique ids.
2. **A game that goes from Q4 tied straight to OT** sends one "close" push, not a second one for OT. Both share the `close:<gameId>` key. Task 2 test: both conditions map to the same key.
3. **A server restart mid-Q4** must not resend a close alert. `push_log` is persistent, which the existing `sendPushOnce` already guarantees; Task 3 asserts `push_log` rows after two triggers.
4. **A rescheduled game** (tip-off moved) sends tip-off for the new time only. The key is per game, so a reschedule after the send doesn't resend. That's accepted, and noted in the code comment.
5. **Pins from a logged-out session** sync on login without going over 3. Task 4: the merge keeps at most 3, with the server's pins first.

### Task 2: Alert conditions, recipients, copy

**Files:**
- Create: `backend/src/services/teamPush.ts`
- Test: `backend/src/scripts/check-team-push.ts` (section "rules")

**Interfaces:**
- Consumes: `usersWithPref` from Task 1.
- Produces:
  ```ts
  export interface PushGame { id: string; status: string; quarter: number | null; gameClockSeconds: number | null; tipoffAt: string;
    homeScore: number; awayScore: number; homeTeamId: string; awayTeamId: string; homeCode: string; awayCode: string }
  export function tipoffDue(g: PushGame, now: Date): boolean;                        // scheduled, 10–20 min ahead
  export function closeAlert(g: PushGame): "close" | "ot" | null;                     // live Q4 ≤120s margin ≤3 → close; quarter ≥ 5 → ot
  export async function recipientsFor(kind: "team_tipoff" | "team_close" | "team_final", g: PushGame): Promise<string[]>;
  export function message(kind: "team_tipoff" | "team_close" | "team_final", g: PushGame, lang: "en" | "el", extra?: { ot?: boolean; player?: { name: string; points: number } }): { title: string; body: string; url: string };
  export function notifyTipoff(g: PushGame): void;   // fire-and-forget wrappers around sendPushOnce
  export function notifyClose(g: PushGame): void;
  export function notifyFinal(g: PushGame): void;    // adds the pinned player's line per user
  ```
